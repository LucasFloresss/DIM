# DIM (Dispensador inteligente de medicamentos)

Visão geral:
 Dispensador automático de comprimidos com alarme: dispositivo eletrônico projetado para armazenar e liberar doses de medicamentos em horários programados. Possui temporizador, alarme sonoro/visual e mecanismo de liberação controlada, auxiliando na organização e no cumprimento dos horários de medicação.

🎯 Objetivos:
Auxiliar na organização e no cumprimento dos horários de medicações.

Possui temporizador, alarme sonoro/visual e mecanismo de liberação controlados.

💎 Detalhes
- Estrutura em plástico, com compartimentos internos removíveis para facilitar a limpeza.
- Display e botões para configurar horários e doses. (ou página web)
-  Mecanismo motorizado, como servo ou motor de passo, que libera apenas a dose correspondente
